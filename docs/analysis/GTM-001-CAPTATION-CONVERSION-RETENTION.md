## PARTE II: ESTRATEGIA DE CONVERSIÓN

## 4. Principios de conversión

1. **Precio visible siempre:** Sin "solicitar presupuesto". El cliente sabe cuánto cuesta antes de decidir.
2. **Mínima fricción:** Formularios < 5 campos. Pago integrado. Sin registro previo obligatorio.
3. **Prueba social:** Testimonios reales. Nº de expedientes realizados. Valoraciones.
4. **Garantía:** Garantía de devolución si el cliente no queda satisfecho (reduction de riesgo).
5. **Urgencia justificada:** "Plazos normativos" o "disponibilidad de ATs" como drivers (no falsa urgencia).

---

## 5. Embudo de conversión por producto

### 5.1 ATI-01 Segunda Opinión (99€)

```
Landing page
  → CTA "Solicitar Segunda Opinión"
    → Formulario (4 campos: nombre, email, tlf, dirección)
      → Subida de archivo (certificado PDF)
        → Pago (Stripe integrado)
          → Confirmación + email
```

**Optimizaciones clave:**
- Test A/B: precio visible en hero vs en sección inferior
- Test A/B: CTA "Solicitar" vs "Contratar" vs "Revisar mi certificado"
- Trust signals: AT colegiado, logotipos colegios, testimonios reales
- Abandono recuperable: email de recordatorio si no completa pago en 24h

### 5.2 ATI-03 ITE (desde 299€)

```
Landing page específica
  → Selector: "Vivienda individual" vs "Comunidad de propietarios"
    → Formulario (6 campos: dirección, año construcción, nº vecinos, contacto)
      → Precio calculado automáticamente
        → Pago o solicitar contacto AT
```

**Optimizaciones clave:**
- Calculadora de precio en tiempo real (según nº vecinos)
- CTA dual: "Contratar ahora" (pago) + "Hablar con un asesor" (consulta)
- Testimonios de administradores de fincas

### 5.3 GTD-01 ISV / GTD-03 Custodia

```
Post-dictamen ATI-01
  → Email/recomendación: "Tu certificado está revisado. ¿Quieres organizar toda la documentación de tu vivienda?"
    → CTA a landing page ISV
      → Previsualización del informe
        → Contratación
```

**Optimizaciones clave:**
- Cross-sell natural: ofrecer ISV cuando el cliente acaba de recibir valor (dictamen ATI-01)
- Previsualización del informe (demo visual)
- Precio en pack: ATI-01 + ISV = 149€ (ahorro 49€)

### 5.4 PLT-01 (AT Partner)

```
Landing page AT
  → CTA "Quiero ser partner"
    → Formulario (5 campos: nombre, email, tlf, nº colegiado, años experiencia)
      → Verificación de colegiatura
        → Onboarding guiado
          → Primer expediente asistido
```

**Optimizaciones clave:**
- Caso de éxito real de otro AT
- Simulador de ingresos: "Con X expedientes/mes, ingresas Y€"
- Sin compromiso: "Empieza con un expediente de prueba"

## PARTE III: ESTRATEGIA DE FIDELIZACIÓN

## 7. Ciclo de fidelización

```
Primera compra
    ↓
Entrega de valor inmediata (48h)
    ↓
Email post-servicio + recomendación personalizada
    ↓
Cross-sell natural (producto complementario)
    ↓
Suscripción (Custodia / Newsletter)
    ↓
Alertas periódicas (caducidades, novedades normativas)
    ↓
Referidos (programa de recomendación)
    ↓
Segunda compra (nuevo producto o recurrencia)
    ↓
Cliente prescriptor
```
