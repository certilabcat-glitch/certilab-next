## 2. Posicionamiento global del ecosistema Certilab

### 2.1 Propuesta de valor global

> **Certilab es la primera plataforma independiente que audita, documenta y certifica la situación técnica de tu vivienda, con la garantía de Arquitectos Técnicos colegiados y una metodología transparente.**

### 2.2 Atributos de marca global

| Atributo | Descripción |
|----------|-------------|
| **Independencia** | Sin conflicto de interés. No emitimos certificados, los auditamos. |
| **Rigor técnico** | Metodología PITR™ validada por ATs colegiados. |
| **Digitalización** | Proceso 100% online desde la solicitud hasta el dictamen. |
| **Transparencia** | Observatorio público con datos del mercado. |
| **Escalabilidad** | Plataforma SaaS que democratiza servicios tradicionalmente caros. |
| **Confianza** | Dictamen emitido por AT colegiado con responsabilidad profesional. |

- **Arquetipo:** El Juez / El Experto (justicia + conocimiento)
- **Tono:** Técnico pero accesible. Riguroso pero cercano.
- **Personalidad:** Como un arquitecto de confianza que habla claro.
