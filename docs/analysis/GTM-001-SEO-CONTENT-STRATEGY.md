## PARTE I: ESTRATEGIA SEO POR PRODUCTO

## 1. Principios SEO

1. **SEO es el canal principal** de captación. Coste marginal bajo, efecto acumulativo.
2. **Contenido de autoridad técnica** vs contenido genérico. Competimos con profundidad, no con volumen.
3. **Search Intent primero:** Cada producto resuelve una intención de búsqueda específica.
4. **Clúster de contenido:** Artículo pilar → artículos satélite → landing page producto.
5. **SEO local:** Cataluña primero (donde estamos), luego expansión nacional.
6. **Featured Snippets:** Contenido estructurado para capturar posición 0.
