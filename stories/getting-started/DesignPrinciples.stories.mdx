# Design Principles

The five principles that guide every design decision in Certilab.

---

## 1. Clarity

Every interface should communicate its purpose immediately.

- Users should understand what a screen is for within seconds.
- Use clear labels, logical grouping, and progressive disclosure.
- Avoid decorative ambiguity.

## 2. Trust

Visual language must convey professionalism and reliability.

- Certilab handles legally binding documents (energy certificates, ITEs).
- The interface must feel solid, predictable, and secure.
- Use established patterns. Avoid novelty for its own sake.

## 3. Efficiency

Minimize friction. Users should complete tasks with the fewest possible steps.

- Default paths should be obvious and fast.
- Advanced options should be available but not in the way.
- Every additional click must be justified.

## 4. Consistency

One component, one behavior, everywhere.

- Reuse patterns across the platform.
- If a button looks the same, it should behave the same.
- Consistency reduces cognitive load and errors.

## 5. Accessibility

No user is left behind.

- Meet WCAG 2.1 AA as a minimum.
- Design for keyboard, screen reader, and touch.
- Color is never the sole conveyer of information.

## Applying the Principles

When making a design decision, ask:

1. Does this make the interface clearer?
2. Does this inspire trust?
3. Does this make the user more efficient?
4. Is this consistent with the rest of the platform?
5. Is this accessible?

If the answer to any is "no", the decision needs revisiting.
