# Certilab Design System

**Version 1.0.0-rc1**

The official design system for the Certilab platform. This is the single source of truth for all reusable components, design tokens, and UI patterns.

## What is Certilab?

Certilab is a digital platform for energy certification and technical architecture inspections in Catalonia. The platform processes certificates of energy efficiency, technical inspections of buildings (ITE/IEE), and related documentation.

## Design Principles

- **Clarity**: Every interface should communicate its purpose immediately.
- **Trust**: Visual language must convey professionalism and reliability.
- **Efficiency**: Minimize friction. Users should complete tasks with the fewest possible steps.
- **Consistency**: One component, one behavior, everywhere.
- **Accessibility**: No user is left behind.

## Structure

- **Foundations**: Design tokens (colors, typography, spacing, radius, motion)
- **Atoms**: Basic UI components (Button, Input, Badge)
- **Molecules**: Composed components (Card, FormField)
- **Organisms**: Complex sections (Header, DataTable)
- **Templates**: Page layouts
- **Pages**: Full page examples
